Unified search

Blockchain investigation

Unified search automatically resolves supported blockchain identifiers.

Supported: Bitcoin, Ethereum, Base, Arbitrum, BNB Smart Chain, Polygon and TRON addresses, plus supported transaction identifiers.

Use public blockchain identifiers only. Never enter a private key or recovery phrase.

Ethereum is the default for shared EVM syntax. Choose a network hint for Base, Arbitrum, BNB Smart Chain, Polygon or TRON transaction IDs.

Bitcoin needs no key. EVM lookups use Etherscan on the server; Ethereum may use optional Alchemy balance fallback. Etherscan plan coverage varies by chain.
